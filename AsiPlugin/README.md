# 《侠盗猎车手2》简体中文汉化 - ASI插件

> [!TIP]
> 本项目使用 [CMake](https://cmake.org/download/) 和 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) 构建。

## 构建

配置并生成构建文件：

```
cmake --preset VS2026-Win32
```

构建 Debug 版本：

```
cmake --build --preset debug
```

构建 Release 版本：

```
cmake --build --preset release
```
